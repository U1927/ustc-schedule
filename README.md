# 科大日程

面向中国科大的个人日历。将本科课表、青春科大活动、普通日程和截止事项放在一起。日历以北京时间显示，同一个账号可在 Android、iPhone、Windows 和 macOS 间同步。

## 本地运行

安装 Node.js 24 或更新版本，然后在项目目录运行：

```sh
npm ci
npm start
```

在浏览器打开 <http://localhost:3000>，创建科大日程账号。账号由本应用管理，与学校统一身份认证独立。数据库默认保存在 `data/schedule.sqlite`。

## 在多台设备使用

在一台持续运行的主机上启动应用，将其放在 HTTPS 反向代理之后，通过同一个 HTTPS 地址访问。复制 `.env.example` 为 `.env`，把 `APP_ORIGIN` 设为浏览器实际访问的来源，例如 `https://calendar.example.com`。同机反向代理可继续使用默认的 `127.0.0.1:3000`。部署在容器时请设置 `HOST=0.0.0.0` 并挂载持久化数据目录。备份 SQLite 时请使用 SQLite 在线备份，或停止应用后备份数据目录。

| 设备 | 安装方式 |
| --- | --- |
| Android | 在 Chrome 的网站菜单中安装或添加到主屏幕 |
| iPhone | 在 Safari 的分享菜单中添加到主屏幕。推送需要 iOS 16.4 或更新版本 |
| Windows | 在 Edge 或 Chrome 中安装应用 |
| macOS | 在支持的 Safari 中添加到程序坞，或用 Chrome 安装 |

登录后，打开「设备与提醒」，为当前设备开启通知并发送测试提醒。每项日程都支持到时提醒、自定义提前分钟数或关闭提醒。截止事项只需要一个截止时间。后台通知依赖服务持续运行、浏览器推送服务和设备的通知权限。

如果只供个人使用，可在创建账号后设置 `DISABLE_SIGNUP=1` 并重启。生产环境可用 `PUSH_CONTACT=mailto:你的联系邮箱` 设置推送联系地址。

## 导入校园日程

- **本科课表**。在登录后的教务系统里打开「我的课表」，用应用内提供的 Chrome / Edge 扩展下载当前学期的课表。回到应用上传、核对并添加。缺少学期日期时可手动填写第一教学周的周一。也支持导入已有 .ics 文件。识别不到的课程会在预览中提示，临时调课以教务系统为准。
- **青春科大活动**。应用内可浏览 Life@USTC 提供的青春科大公开活动镜像，每条活动可一键添加到日历。也能在校方活动详情页通过扩展导出，或复制正文导入。报名请在青春科大完成。
- **重复导入**。同一来源和标识的记录会跳过。日历保留你已添加的版本，可以手动编辑调课或活动改期。每次导入后，其他设备打开相同账号即可看到。

扩展通过浏览器的当前标签页权限在学校网站内读取课表或活动详情。导出文件仅包含识别日程所需的字段。普通日程、课表和活动的最终保存内容写入你运行的科大日程服务。

## 开发

```sh
npm test
```

前端位于 `public/`，学校页面导入扩展位于 `extension/`，Node 服务位于 `server/`。应用在提供扩展下载时会把共享解析模块一起打包。课表格式参考 [Life@USTC 的课表适配器](https://github.com/Life-USTC/client-core/blob/main/ustc/course_table.go)，节次时间参考 [中国科大本科生学习指南](https://www.teach.ustc.edu.cn/wp-content/uploads/2025/08/2025%E6%9C%AC%E7%A7%91%E5%AD%A6%E4%B9%A0%E6%8C%87%E5%8D%97.pdf)。
