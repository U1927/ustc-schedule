# Gemini 界面设计任务

为「科大日程」设计日历、当日安排和校园导入的桌面与手机界面。主流程是打开后看今天、快速新增日程、查看近期截止事项、把活动一键加入日历。请输出一套可直接实现的高保真方案及对应的 HTML/CSS 调整。

- 桌面提供月历和选中日期的详情，手机保留单手可达的校园导入与提醒入口。
- 课程、活动、普通日程、截止事项需要有清楚的视觉区分。请同时用标签表达类别，并保留看得清的焦点状态。
- 截止事项显示一个截止时间。时间字段使用北京时间，提前提醒支持预设和自定义分钟数。
- 保留课程导入预览、活动一键添加、登录与设备提醒设置的操作和错误反馈。为长中文标题、空状态、网络错误和重复导入预留空间。
- 入口为 `public/index.html` 和 `public/styles.css`。保留 `public/app.js` 使用的表单字段、元素 ID 和 data 属性。使用虚构账号、课程和活动作为设计样例。
